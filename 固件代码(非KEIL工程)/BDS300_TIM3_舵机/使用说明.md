# 四路BDS300舵机控制：STM32F103C8T6标准库

把 `servo.c`、`servo.h` 加入**板3**的标准库工程。驱动使用TIM3，直接调用STM32F10x标准库，不使用HAL，不使用中断或延时，不配置系统时钟。

现增加`Servo_SetAngle()`，按2026-10-02用户提供的图1，暂用20ms周期、500～2500µs对应0～180°的线性关系。原来的周期和脉宽接口保留。

**图1是以180°舵机为例的通用说明；图2是BDS300产品参数图，没有写明PWM周期、脉宽范围或总行程。** 因此以下是按用户提供的初步判断采用的可调整参数，不能称为已确认的BDS300官方控制协议。

## 暂定参数

所有角度映射参数集中在`servo.h`：

| 宏 | 暂定值 | 含义 |
|---|---|---|
| `SERVO_PERIOD_US` | 20000 | PWM周期20ms，即50Hz |
| `SERVO_MIN_PULSE_US` | 500 | 目标0°对应的高电平脉宽 |
| `SERVO_MAX_PULSE_US` | 2500 | 目标180°对应的高电平脉宽 |
| `SERVO_MAX_ANGLE_DEG` | 180.0f | 暂定目标角度上限 |

修改这些宏后重新编译。脉宽端点应满足`0 < MIN < MAX < 周期 <= 65535`，角度上限应大于0。默认映射为：

| 目标角度 | 高电平脉宽 |
|---|---|
| 0° | 500µs |
| 45° | 1000µs |
| 90° | 1500µs |
| 135° | 2000µs |
| 180° | 2500µs |

```text
pulse_us = 500 + angle_deg / 180 × (2500 - 500)
```

计算结果四舍五入到整数微秒，支持小数角度。这是目标指令的换算，不代表舵机实测角度或实际定位精度；腿部运动学关节角还需结合安装零位、方向和可用机械范围另行换算。

图1的“总间隔2ms”可理解为2.5ms与0.5ms的脉宽跨度，不是PWM重复周期。图2的“0.13s/60°（7.4V）”是转动速度指标，也不是PWM周期。

## 接线

依据工程中2026-09-29的板3、板2网络表：

| id | 板3引脚 | 定时器通道 | 网络 | 板2舵机接口 |
|---|---|---|---|---|
| 0 | PA6 | TIM3_CH1 | PWM1 | U8，1脚 |
| 1 | PA7 | TIM3_CH2 | PWM2 | U9，1脚 |
| 2 | PB0 | TIM3_CH3 | PWM3 | U10，1脚 |
| 3 | PB1 | TIM3_CH4 | PWM4 | U11，1脚 |

板2舵机接口2脚接7.4V电源，3脚接GND；板3与板2共地。PWM为板3输出的3.3V逻辑信号。7.4V是舵机电源，不是PWM高电平；BDS300是否保证识别3.3V仍以模块规格或实测为准。

用户提供的BDS300产品图标注：橙色为PWM信号线，红色为VCC电源线，棕色为GND地线；工作电压7.4V，堵转扭力10kg·cm。堵转扭力不能用来推导PWM周期或脉宽。

**板1电机驱动与板3舵机驱动分别在两块MCU运行。** 板1的PA6/PA7用于SPI1，PB0用于DRV8323使能，PB1用于编码器CS。不要将本模块直接与板1的六步换相模块合并运行在同一组引脚上。

## 三个接口

```c
Servo_Result Servo_Init(uint16_t period_us);
Servo_Result Servo_SetPulse(uint8_t id, uint16_t pulse_us);
Servo_Result Servo_SetAngle(uint8_t id, float angle_deg);
```

- `period_us`：重复周期，单位微秒，四个通道共用，允许2～65535。
- `pulse_us`：高电平持续时间，单位微秒，范围0～`period_us-1`。
- `id`：0～3，对应四个舵机。
- `angle_deg`：目标角度，单位度，默认允许0～180，支持小数。
- 返回`SERVO_OK`（0）表示成功，其余错误码见`servo.h`。

`Servo_SetAngle()`拒绝越界、NaN、无穷大和非法id，错误时保留原输出，不会静默截断到端点。为了保证整段角度映射都能输出，此接口要求当前周期大于`SERVO_MAX_PULSE_US`。

`Servo_SetPulse()`仍是原始波形接口，只检查定时器范围，不把脉宽限制到500～2500µs。正常位置控制优先使用角度接口；进行原始脉宽试验时由应用选择合适范围。

## 使用例子

下例只给第一个舵机发送暂定90°（1500µs）指令，不自动扫到0°或180°。初次验证先让输出轴无负载、避开连杆机械限位，从中间位置附近的小范围变化检查实际响应，再确定可用范围。

```c
#include "servo.h"

/* 放在你原来的main中；启动文件已经调用SystemInit，无需再次配置系统时钟。 */
Servo_Result result;

result = Servo_Init(SERVO_PERIOD_US); /* 暂定20ms周期；四路最初均不发脉冲 */
if (result != SERVO_OK) {
    /* 初始化失败，不继续发送控制指令。 */
    while (1) { }
}

result = Servo_SetAngle(0u, 90.0f); /* 第一个舵机：暂定90度，发出1500us脉冲 */
if (result != SERVO_OK) {
    while (1) { }
}

while (1) {
    /* TIM3硬件会持续产生波形，无需反复调用Servo_SetAngle。 */
    /* 后续收到新的目标角度，再调用Servo_SetAngle修改对应通道即可。 */
}
```

另外三个舵机用`Servo_SetAngle(1u, angle_deg)`、`Servo_SetAngle(2u, angle_deg)`、`Servo_SetAngle(3u, angle_deg)`设置。例如`Servo_SetAngle(0u, 95.0f)`将第一个舵机的脉宽改为约1556µs；仍须检查返回值。

停止某个通道发送脉冲：

```c
result = Servo_SetPulse(0u, 0u);
```

它将在下一次周期边界生效，最多等待一个完整周期。**停止脉冲不等于断电，也不保证舵机松开或停止保持位置**；失去信号后的行为由舵机内部控制器决定。

注意：`Servo_SetAngle(0u, 0.0f)`会发出500µs的目标位置脉冲，**不是停止指令**。

要改变四路共同的周期，可重新调用`Servo_Init(new_period_us)`。重新初始化会将四路脉宽全部清零，再分别设置所需脉宽。无效参数或不支持的时钟会返回错误并保留此前配置。

## 定时器怎么算

计数频率设为1MHz，每计数一次就是1µs：

```text
TIM3时钟：APB1不分频时=PCLK1，APB1分频时=2×PCLK1
PSC = TIM3时钟 / 1000000 - 1
ARR = period_us - 1
CCR1/2/3/4 = 对应通道的pulse_us
```

例如HCLK=72MHz、PCLK1=36MHz时，TIM3时钟为72MHz；20ms周期对应PSC=71、ARR=19999，1500µs高电平对应CCR=1500。其占空比为7.5%，但舵机位置指令应按**脉宽**设置，而非沿用电机驱动的0～1000占空比。

CCR启用预装载，因此更新脉宽不会在当前脉冲中途立即改变比较值。连续写四路跨越周期边界时，可能有通道下一周期才更新；当前接口不提供四路原子同步提交。

本模块独占TIM3及上述四个GPIO。沿用启动阶段`SystemInit()`完成的系统时钟配置，只读取频率、开启相关外设时钟并设置TIM3；没有再次调用`SystemInit()`或重设PLL。初始化后不要另行修改这些外设或系统时钟。BDS300控制协议或可用机械范围确认后，再调整头文件中的暂定映射。
