# 板三 TIM4 裸机跳跃例程（IMU963RA）

本例使用STM32F103C8T6标准库，不依赖FreeRTOS。main_example.c仅用于独立测试，不能与原main.c同时编译；合并时取所需初始化和主循环调用。

## 定时器

- 要求TIM4输入时钟为72MHz，与当前核心板SystemInit设置一致。
- PSC=7200-1：计数频率10kHz，每个计数0.1ms。
- ARR=65535：65536次计数，6.5536秒回绕。
- JumpTick_Millis返回CNT/10；检测到UIF后返回JUMP_TICK_EXPIRED，不能把回绕误当新起点。
- 不开启TIM4中断，不占GPIO，不重新设置系统时钟。
- Stop先关闭TIM4，再产生UG将CNT/预分频内部计数清零并装载配置，最后清UIF。不是把ARR复制给CNT。

已修复divider未赋值的问题；直接使用7200-1，不依赖未初始化的局部变量。若以后改变系统/APB时钟，需要重新核对这个预分频值。

## 初始化与调用

例程先Serial_Init，再初始化TIM4、TIM3舵机和IMU963RA。IMU初始化由现有驱动配置SPI2和GPIO，不再调用旧MPU9250或额外IIC板级接口。IMU初始化0表示成功，SPI错误标志也必须为0。

调试器或按键/CAN处理写入g_jump_command：0无请求、1开始、2取消。只保存最近请求，重复START不重启正在执行的跳跃。
TakeCommand用Cortex-M3独占读写原子取出并清零，不关闭全局中断。当前工程的旧CMSIS宏在ARMCC5下有deprecated提示，但编译通过。

START → Jump_Start(0)成功后开启TIM4 → 主循环用实际计时调用Jump_Update → 返回LANDED/ERROR或收到STOP后关闭并清零TIM4。

主循环可以快速轮询；跳跃模块内部20ms至多读取一次加速度，匹配当前约52Hz加速度输出。处理其他任务时避免长时间Delay或CAN忙等，否则会影响计数与动作时机。输出给舵机的其他控制器在跳跃期间应让出控制。

STOP取消后续动作但保留舵机目标，不是切断舵机电源。全部Jump接口和SPI读操作都在主循环执行。

## 文件

加入jump.c、jump_tick.c、leg_ik.c、servo.c、zf_device_imu963ra.c，以及当前Serial/Delay/标准库依赖。使用本例main时，保留项目里其他中断需要的全局变量，或移除不使用的业务模块。

先填写jump.h中舵机安装映射、角度限位、最低/最高/缓冲腿高。未填写时返回ERROR；本次没有代填未知实物参数。BDS300脉宽与角度关系仍需确认。
