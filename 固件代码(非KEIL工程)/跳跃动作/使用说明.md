# 跳跃动作：核心控制板 IMU963RA 适配版

2026-10-19：只适配接口、量程、采样周期和计时器，不改变跳跃阶段、阈值、动作顺序或五次缓冲曲线。

## 接入现有工程

使用 jump.c/.h、leg_ik.c/.h、servo.c/.h、zf_device_imu963ra.c/.h。
舵机使用 TIM3（PA6、PA7、PB0、PB1）；IMU963RA 使用 SPI2（PB12 软件片选、PB13/14/15）。逐飞原始数据读取函数保持原样。

先初始化舵机和 IMU：Servo_Init 成功返回 SERVO_OK（0）；imu963ra_init 成功返回0，同时检查 imu963ra_spi_error 为0。
Jump_Start/Jump_Update 使用同一个毫秒时基，放在主循环调用。可用配套 TIM4 例程，也可沿用自己的毫秒计时。

当前核心板主程序尚未合并跳跃调度；本次修改的是本目录原文件和非KEIL逆解依赖，不会自动起跳。

## 参数

jump.h 集中保留宏接口：

- JUMP_GEOMETRY 已沿用当前核心板杆长 `{60,90,90,60,37.5}` mm。
- JUMP_SERVO_IDS 按左AB、左ED、右AB、右ED排列，默认 `{0,1,2,3}`；按实际接线核对。
- JUMP_OFFSET_DEG、JUMP_DIRECTION：舵机指令角 = offset + direction × 几何角。direction填+1或-1，offset填实测安装偏置。
- JUMP_MIN_DEG、JUMP_MAX_DEG：四个舵机各自的可用指令角范围。
- JUMP_LOW_MM、JUMP_HIGH_MM、JUMP_BUFFER_MM：仍需填写实测可用腿高，满足 `0 < LOW < BUFFER < MID < HIGH`。MID默认取LOW和HIGH的平均值。
- 未填写的NAN或direction=0会使Jump_Start返回JUMP_ERROR，不会发送动作。BDS300的脉宽与角度映射也仍需实测确认。

Get_Angles(x,y,angle) 输入两腿共用的足端坐标(mm)，输出四个舵机指令角(度)。局部原点为AE中点、+y向下；当前逆解保留钻石形检查。失败不修改输出。

## 采样和量程

JUMP_READ_ACCEL 默认调用 jump.c 内部的 Jump_ReadAccel：调用逐飞 imu963ra_get_acc()，检查 imu963ra_spi_error，成功后复制三个原始轴值。
读取失败返回0，不会当作0g继续判断。SPI2和Jump操作在同一主循环执行，不能与中断中的SPI访问交叉。

JUMP_ACCEL_LSB_PER_G 使用 imu963ra_transition_factor[0]，跟随IMU实际初始化量程。当前±8g对应驱动中的约4098 LSB/g；不会继续用旧MPU的16384除数。

JUMP_SAMPLE_MS 改为20ms，匹配当前IMU约52Hz的加速度输出与20ms姿态循环。Jump_Update可每1~20ms调用，内部每20ms至多采样一次。超过40ms的间隔仍会清空连续样本计数。若改变IMU输出频率，需要同步调整周期，不能把缓存旧数据多次当作新样本。

离地仍要求连续3次低于0.35g；落地仍要求连续4次高于0.8g。改为20ms后，这些确认过程会比原5ms采样慢；本次保留原阈值和样本数，没有另行调参。

## 保留的动作逻辑

最低目标 → 等待下蹲 → 最高目标 → 连续低g确认腾空 → 收到最低 → 等待后放到中间高度 → 连续触地迹象 → 平滑屈腿到BUFFER。

Jump_Start立即下发最低目标；不要每次循环重复Start。Jump_Update返回RUNNING时继续调用；LANDED表示已估计触地且目标轨迹完成，不保证舵机实际到位或机身站稳。若在放到中间高度之前提前触地，则保持最低目标并返回LANDED。

触地后曲线仍为 `s = 10u^3 - 15u^4 + 6u^5`，`y = MID + (BUFFER-MID)*s`。
其峰值速度为 `1.875*(MID-BUFFER)/T`，原来的1875毫秒换算、最大腿高指令速度限制、迟到时不追赶位移策略都保留。

原有60ms落地屏蔽窗口也保留。该窗口可能延迟触地检测；平滑位置指令不等于力控，也不能保证消除落地冲击。

Jump_Stop或ERROR仅停止后续目标切换，舵机继续保持最后的目标。跳跃期间，其他PID/调腿任务不能同时覆盖这四路舵机；在现有主程序合并时要做输出互斥。普通控制器恢复后应从合理目标接管。

## 配套修正与验证

非KEIL版 leg_ik.h 的三个全局对象改为extern声明，定义移到leg_ik.c，避免与jump.c同时编译时重复定义。逆解计算未改。
TIM4例程固定PSC=7200-1、ARR=65535，前提是当前启动代码配置的TIM4时钟72MHz。未改变SystemInit；每次跳跃只开启这一次计时，结束关闭并用UG清零。

验证：20ms及快速轮询均能完成模拟流程；±2/4/8/16g量程换算、静止1g不会误判腾空、SPI失败、提前落地、毫秒回绕、未填参数拒绝输出均已测试。使用当前核心板真实驱动的临时Keil工程编译链接为0错误、0警告；独立main_example编译通过，旧CMSIS独占访问宏产生两条deprecated提示。未烧录、未实机验证。
