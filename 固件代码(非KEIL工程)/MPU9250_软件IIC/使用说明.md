# 从SDA、SCK开始的软件I²C与MPU9250驱动

核心代码不依赖STM32标准库或HAL；F103、F407等平台只需实现硬件接口。使用C99或更新标准，Keil旧编译器需开启C99模式。

## 1. 文件分工

| 文件 | 作用 |
|---|---|
| iic_port.h | 声明由单片机提供的5个硬件接口 |
| soft_iic.c / soft_iic.h | START、STOP、收发字节、ACK/NACK、寄存器单字节和连续读写 |
| mpu9250.c / mpu9250.h | 芯片身份检查、复位、初始化、读取六轴及磁力计 |
| port_stm32f4_hal.c.example | 可选的F407 HAL移植示例，PB6=SCK、PB7=SDA；需要使用时才复制进工程 |
| tests/ | 主机模拟检查，不加入单片机固件 |

## 2. 只有SDA(0/1)、SCK(0/1)还不够读取

这两个函数是输出动作。读取ACK和数据，必须增加读取SDA真实电平的函数。

```c
void SDA(uint8_t level);         // 0拉低，1释放
void SCK(uint8_t level);         // 0拉低，1释放
uint8_t SDA_Read(void);          // 读取真实输入电平，0或1
uint8_t SCK_Read(void);          // 读取真实输入电平，等待SCL变高并判断超时
void IIC_DelayUs(uint32_t us);   // 可靠的微秒延时
```

SCK在I²C中一般叫SCL，这里沿用你指定的名称。SDA和SCK都使用开漏输出，输出1的含义是释放线路，不是推挽强行驱动高电平。需要外部上拉电阻；短线可从4.7kΩ起步，结合已有模块上拉及总线电容确认。GPIO读函数读取IDR，不读取ODR。MPU9250使用I²C时，nCS应保持高电平，AD0确定为低或高，不要悬空；成品模块可能已经处理这些引脚。

本实现是单主机软件I²C，不能从多个中断/任务同时调用。存在RTOS时应在外层加互斥锁；不要让另一个任务在一次寄存器读写中间改动SDA/SCK。长中断会降低总线速度。总线被拉低时返回错误，不自动发送恢复脉冲；排除接线/掉电器件等原因后再重试。

## 3. I²C接口怎么调用

```c
uint8_t id;
uint8_t data[14];
IIC_Status status;

/* 地址传7位值0x68，不传旧示例里的0xD0。 */
status = IIC_ReadReg(0x68, 0x75, &id);
if (status == IIC_OK) {
    /* MPU9250的id应该是0x71。id==0不是“通信失败”的返回码。 */
}

status = IIC_WriteReg(0x68, 0x6B, 0x01); // 唤醒并选择时钟
status = IIC_ReadRegs(0x68, 0x3B, data, sizeof(data));
```

单字节写寄存器：

`START → 地址+W → 从机ACK → 寄存器地址 → 从机ACK → 数据 → 从机ACK → STOP`

连续读寄存器：

`START → 地址+W → ACK → 寄存器地址 → ACK → 重复START → 地址+R → ACK → 数据1 → 主机ACK → … → 最后数据 → 主机NACK → STOP`

0x68的线上写地址字节是0xD0，读地址字节是0xD1，由驱动内部生成。AD0为高改传0x69。AK8963传0x0C。ACK为低电平，NACK为高电平。

IIC_ERR_NACK表示从机没应答；IIC_ERR_SCL_TIMEOUT表示释放SCK后实际电平没有在允许时间内变高；IIC_ERR_BUS_BUSY表示开始通信时SDA被拉低；IIC_ERR_STOP表示结束时SDA仍未释放。读取失败时不要使用可能部分更新的原始缓冲区。寄存器地址自动递增由从设备实现，不是所有I²C器件都支持这里的8位寄存器协议。

## 4. 初始化顺序和参数

`GPIO开漏/延时初始化 → 总线检查 → WHO_AM_I → 软件复位 → 唤醒/选时钟 → 量程/滤波/采样 → 可选磁力计初始化`

MPU9250_Init先等上电稳定，检查WHO_AM_I=0x71，再执行下表。初始化各阶段的100ms延时是保守工程取值，不意味着每个寄存器写入都要等待100ms。普通读写不加5ms之类的无关等待。

| 寄存器 | 地址 | 值 | 含义 |
|---|---|---|---|
| PWR_MGMT_1 | 0x6B | 0x80 | 复位，等待100ms |
| PWR_MGMT_1 | 0x6B | 0x01 | 退出休眠；自动选择可用的PLL/内部时钟，再等待100ms |
| PWR_MGMT_2 | 0x6C | 0x00 | 打开全部六个轴 |
| USER_CTRL | 0x6A | 0x00 | 不启用FIFO和MPU内部I²C主机 |
| FIFO_EN | 0x23 | 0x00 | 关闭FIFO写入 |
| CONFIG | 0x1A | 0x03 | 陀螺仪低通档位3，约41Hz |
| GYRO_CONFIG | 0x1B | 0x18 | ±2000°/s，FCHOICE_B=00 |
| ACCEL_CONFIG | 0x1C | 0x00 | ±2g；保留位写0，纠正旧代码的0x01 |
| ACCEL_CONFIG2 | 0x1D | 0x03 | 加速度低通档位3，约40Hz |
| SMPLRT_DIV | 0x19 | 0x04 | 当前滤波配置下1kHz/(1+4)=200Hz |
| INT_PIN_CFG | 0x37 | 0x00 | 初始不开旁路 |
| INT_ENABLE | 0x38 | 0x01 | 原始数据就绪，可轮询INT_STATUS；不要求INT脚接单片机 |

常规可读写配置执行写后读取校验；复位位不做立即读回相等检查，因为会自动清除。默认参数用于跑通测量，不是整机平衡控制最终调参。若把SMPLRT_DIV改为7，则当前滤波配置下为125Hz；若改量程，单位换算也必须相应修改。

MPU9250_InitMag独立执行：打开旁路 → 确认AK8963的WIA=0x48 → 复位磁力计 → 掉电模式 → Fuse ROM模式读取ASA系数 → 掉电模式 → CNTL1=0x16（16位、连续模式2，100Hz）。各模式转换间等待1ms。只需要加速度和角速度时不必调用。

## 5. 使用示例

下面假设你的工程已经实现时钟初始化和上述5个接口；示例的Board_IIC_Init可参考随附F407 HAL文件。如果已有SDA/SCK定义，不要重复添加。

```c
#include "mpu9250.h"
#include "iic_port.h"

MPU9250 imu = {0};
MPU9250_Raw raw;
float magnetic_uT[3];
MPU9250_Status status;

/* 放在自己的main初始化部分： */
Board_IIC_Init();  // GPIO开漏、上拉、可靠的微秒延时；时钟先由你的工程配置
status = MPU9250_Init(&imu, MPU9250_ADDR_AD0_LOW);
if (status != MPU9250_OK) {
    /* 记录status；若是MPU9250_ERR_IIC，再查看imu.last_iic_status。
     * 不要进入依赖IMU数据的电机控制；交给应用决定报错/重试。
     */
}

/* 必须在上面的初始化成功后调用；磁力计不需要可以省略。 */
if (status == MPU9250_OK) {
    status = MPU9250_InitMag(&imu);
    /* 单独检查磁力计结果；磁力计失败不抹掉已成功的六轴初始化状态。 */
}

/* 放在主循环或定时任务中： */
if (imu.initialized) {
    status = MPU9250_ReadRaw(&imu, &raw);
    if (status == MPU9250_OK) {
        float ax_g = raw.accel[0] / 16384.0f;
        float gx_dps = raw.gyro[0] / 16.4f;
        /* ax_g为加速度，gx_dps为角速度。不是姿态角。 */
        (void)ax_g;
        (void)gx_dps;
    } else if (status != MPU9250_NO_NEW_DATA) {
        /* 处理本次读取错误。无新数据时正常等待下一次。 */
    }
}
if (imu.mag_initialized) {
    status = MPU9250_ReadMag(&imu, magnetic_uT);
    /* 只有status==MPU9250_OK时，这次的磁场值才有效。 */
}
```

MPU9250_ReadRaw连续读取14字节，并处理有符号大端数据；MPU9250_ReadMag读取小端数据并包含ST2、检查溢出，以出厂ASA系数修正后输出µT。两者没有新数据时返回MPU9250_NO_NEW_DATA，不要把旧值当新样本。未使用FIFO，轮询过慢会丢弃旧采样；200Hz是芯片配置，不是软件无条件保证能按200Hz交付数据。

磁力计与六轴传感器的坐标方向需要按模块实际安装统一；ASA只修正出厂灵敏度，不代替硬铁/软铁标定。该示例没有陀螺仪零偏标定、姿态融合或机器人控制算法。
