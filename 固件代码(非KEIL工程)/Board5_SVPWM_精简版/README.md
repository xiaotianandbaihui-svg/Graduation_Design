# 板5：双轮 SVPWM 精简版

已按 `毕业设计_最新.epro2` 的 Board5（2026-10-06 18:07:26 保存版）复核：一颗 STM32F103C8T6 + 两颗 DRV8323H。最新引脚与本代码一致，程序逻辑未变，本次仅更新接线说明。工程文件、旧六步换相文件均未修改。采用标准库；只需加入本目录 `svpwm.c/.h` 和所需的 GPIO/RCC/TIM 库，使用你已有的 `Delay_us(uint32_t)`，C99 数学函数由工具链提供。

## 接线与模式

1. **EN已经修复**：U8.PB0、U1.30、U2.30 现在同属EN网络，与本代码共用使能的接法一致。
2. 两颗 MODE 仍都叫 **MODE**，R15/R16 也接在这一公共网络。建议分成 **MODE1、MODE2**，分别通过自己的 R15/R16 接地，**均焊47kΩ**。这份代码只适用于3PWM，不适用于焊0Ω的6PWM。共网情况下，任一电阻焊0Ω都会把两颗MODE都拉低，不能独立选择档位。不能只按外部两个47kΩ并联为23.5kΩ就断言档位一定错误，因为两颗芯片内部的偏置网络也被并联；拆分是与手册单颗配置直接对应、便于独立配置的推荐方案。

其他控制引脚已按最新板5取值：

| 功能 | 电机1，id=0 | 电机2，id=1 |
|---|---|---|
| INHA/B/C | PA1/PA2/PA3 | PB7/PB8/PB9 |
| PWM定时器 | TIM2_CH2/3/4 | TIM4_CH2/3/4 |
| INLA/B/C | PB12/PB13/PB14 | PB15/PB3/PA15 |
| nFAULT | PA8 | PB5 |
| ENABLE | PB0共用 | PB0共用 |

INL由软件控制，运行时全高，停止时全低。DRV在3PWM模式下生成上下桥控制和死区，不需要MCU再输出三路互补PWM。

## 只有三个接口

```c
int  SVPWM_Init(void);
int  SVPWM_Set(uint8_t id, float voltage_deg, uint16_t modulation);
void SVPWM_Stop(uint8_t id);
```

前两个函数返回1成功、0失败。初始化不会自动转动。异常输入或任一驱动报错会关闭双路使能，排查后重新调用Init。故障只在Init/Set时读取，没有占用EXTI。

`SVPWM_Set(0, 30.0f, 100)` 表示：给电机1施加方向为30°、幅值为最大线性幅值10%的**定子电压矢量**。角度允许超出一圈，内部取模；它不是机械角，也不是目标转角。

`modulation` 为0～1000：0高阻停止；1000对应相电压基波峰值约为 `Vbus/sqrt(3)`。它不等于某一相占空比，更不等于电流或速度。举例，12.6V母线下100对应约0.727V的矢量幅值。不能据此保证电机电流很小。

## 一个慢速旋转矢量的调用例子

下面只是开环调制演示：每1ms调用一次更新函数，电压矢量每秒旋转一电圈；不能保证转子跟随，也不是速度闭环。先核对接线和相序，用限流电源验证。开始幅值50只是演示数值，不保证起转或限定电流。

```c
#include "svpwm.h"

static float angle_deg;
static int demo_on;

int MotorDemo_Start(void)
{
    angle_deg = 0.0f;
    demo_on = SVPWM_Init();
    return demo_on;
}

/* 由你的调度代码每1ms调用一次；本文件不再配置系统时钟或中断。 */
void MotorDemo_Tick1ms(void)
{
    if (!demo_on) return;
    angle_deg += 0.36f;                 /* 360度/秒 × 0.001秒 */
    if (angle_deg >= 360.0f) angle_deg -= 360.0f;
    if (!SVPWM_Set(0, angle_deg, 50) || !SVPWM_Set(1, -angle_deg, 50)) {
        SVPWM_Stop(0);
        SVPWM_Stop(1);
        demo_on = 0;
    }
}

void MotorDemo_Stop(void)
{
    demo_on = 0;                       /* 先禁止后续更新再次启动 */
    SVPWM_Stop(0);
    SVPWM_Stop(1);
}
```

两轮相序相同的前提下，上例定子矢量旋向相反；机器人左右轮的前进方向还取决于安装朝向。固定角度只会产生固定电压矢量，不能让电机持续旋转。

## 与原编码器函数如何衔接

`TLE5012B_ReadAngle` 仍返回 `[0,360)` 的机械角；本文件不读取或配置编码器。若后续要按转子位置施加q轴电压，应先标定对应A相正轴的机械零位与编码器方向，再由应用计算：

```c
rotor_electrical_deg = encoder_sign * pole_pairs * (mechanical_deg - zero_deg);
voltage_deg = rotor_electrical_deg + 90.0f;  /* 正q轴；负q轴使用-90度 */
SVPWM_Set(id, voltage_deg, modulation);
```

这里的 `zero_deg` 必须是在**本SVPWM电压矢量0°**对齐得到的零位。原六步代码的矢量0是“A+、B-、C悬空”，其轴与此处的A相正轴不相同，不能未经转换直接使用原六步的零位。编码器正负号也不能因为做了角度取模就省略。上述位置相关电压控制仍没有电流闭环。

## 算法与时间

程序用逆Clarke得到归一化三相电压 `a,b,c`，再给三相共同加上 `0.5-(max+min)/2`，得到三个占空比。公共偏移不改变线电压，使零矢量时间对称分配；在线性区与对称SVPWM等价，所以无需写六套扇区分支。

PWM采用中心对齐。常用72MHz定时器时钟下：PSC=0，ARR=1800，周期为50µs、频率20kHz。程序只读取当前RCC时钟算ARR，不改PLL/APB。两个电机的载波不做相互同步，每一路内部三相共用同一个计数器。

三相CCR启用预装载，批量写入时临时禁止更新事件，避免新旧占空比混用；正常运行由计数器边界统一装载。不在每次更新时强制UG。启动一路时因三相尚为高阻，允许强制UG立即装载首组值。

20kHz是PWM载波频率，并不意味着函数自动每50µs执行一次。应用决定控制周期，三角函数与浮点运算在F103上没有硬件FPU，需要在实际编译优化设置下测量耗时。停止调用会保持最后一次输出，不会自动停机。

## 当前范围

本代码只做电压型SVPWM。板5的SOA/SOB/SOC未接ADC，因此没有电流采样、限流环或完整FOC。0幅值用INL拉低实现高阻；不以三相50%或0%占空比冒充关断。TIM2/TIM4及相关GPIO由本模块独占，不与旧six_step同时运行。原工程未做修改。

参考：DRV8323手册SLVSDJ3D，第32页表8-3（3PWM真值表）、第41页图8-23（MODE）；STM32 RM0008的TIM2/TIM4中心对齐、CCR预装载及UDIS说明。
