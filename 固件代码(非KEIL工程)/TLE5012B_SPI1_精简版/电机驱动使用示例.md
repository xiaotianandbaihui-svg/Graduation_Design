# 六步换相代码怎么用

本例用于**板1：STM32F103C8T6 + DRV8323H + TLE5012B + BDS3620（7对极）**，使用STM32F10x标准库。板3的舵机驱动是另一块MCU的程序，不与板1共用GPIO。

## 先加入哪些文件

加入本目录的`tle5012b.c`、`six_step.c`，包含对应头文件；要运行下面的单次示例，再加入`motor_example.c`、`motor_example.h`。不要同时加入旧目录中的`motor.c`、`motor_port_stm32f103.c`或另一份同名编码器驱动。

应用先完成：

1. 系统时钟：HCLK=72MHz、PCLK1=36MHz。
2. 你已有的`Delay_us(uint32_t us)`初始化，其实现不能占用TIM2/TIM4。
3. SPI1：主机、16位、MSB先、CPOL低、CPHA第二边沿、双线全双工、软件NSS且内部NSS高。默认推挽SSC的SCK不超过8MHz。
4. 两路CS：PA4和PB1设为推挽输出，空闲均为高；沿用你已有的成品编码器模块接线和SPI1初始化。

`SixStep_Init()`负责电机驱动GPIO、TIM2/TIM4和驱动器使能，不负责SPI1。标定或加载标定内部会检查并初始化编码器状态，不必在示例里重复调用`TLE5012B_Init()`。

## 最短的单次运行示例

在你原来的`main()`已经完成上述初始化之后，调用：

```c
#include "motor_example.h"

/* 这段放在main函数内；此前保留你自己的时钟、SPI1、CS和延时初始化。 */
SixStep_Result result;

result = Motor_Example_RunOnce();

if (result != SIX_STEP_OK) {
    /* 查看result错误码；示例已经关断双路，不要在这里自动反复重试标定。 */
    while (1) { }
}

while (1) {
    /* 单次示例已经结束，电机0的驱动输出已关闭。 */
}
```

这个函数执行：

```text
等待编码器启动 → 初始化双路驱动 → 标定电机0
→ 正向5%占空比运行20000次换相更新 → 关闭电机0输出 → 返回
```

标定会转动电机，要求轴可自由转动、使用限流电源。例子中的标定与运行占空比都取50，即5%；这是便于开始调试的示例值，**不是已验证的安全电流、必然启动值或闭环转矩指令**。如果标定失败，应检查返回码、接线与实际对齐运动。

每次`Update`后延时50µs，真实更新间隔还要加上读取编码器、计算和换相的耗时；20000次不等于精确1秒。这个循环用于台架演示。正式控制应测量每路更新间隔，并用自己的调度保证换相频率；不要在换相运行时插入长延时、耗时打印或阻塞通信。

## 自己写控制循环时的调用顺序

1. 调用`SixStep_Init()`一次，成功后继续。
2. 调用`SixStep_Calibrate(0u, 50u, &cal)`，或加载真实标定，成功后继续。
3. 在周期任务中持续调用`SixStep_Update(id, duty, direction)`，每次检查返回值。
4. 任一步失败，都停止后续运行指令并关断输出。`motor_example.c`已经给出了完整的错误处理写法。

`SixStep_Update()`每次会自己读取当前0～360°机械角、转成电角度并换相，调用者不用先读角度，也不用自己算矢量编号。只调用一次不会自动连续换相；需持续周期调用。

| 目的 | 在周期控制里使用的调用 |
|---|---|
| 电机0正向，5%占空比 | `SixStep_Update(0u, 50u, SIX_STEP_FORWARD)` |
| 电机0正向，10%占空比 | `SixStep_Update(0u, 100u, SIX_STEP_FORWARD)` |
| 电机0反向，5%占空比 | `SixStep_Update(0u, 50u, SIX_STEP_REVERSE)` |
| 电机1正向，5%占空比 | `SixStep_Update(1u, 50u, SIX_STEP_FORWARD)` |

`duty`始终为0～1000，方向单独指定。先停止输出并确认电机机械上已经停稳，再在初次调试中尝试反向；`SixStep_Stop()`不会检测转速归零。

## 已保存过标定，就加载真实标定

在`SixStep_Init()`成功之后，用下面的调用**替代**`SixStep_Calibrate()`：

```c
/* saved_cal必须来自同一台电机以前成功的标定。
 * 应用已从Flash读取，并确认版本、完整性及电机编号匹配。 */
result = SixStep_SetCalibration(0u, &saved_cal);
```

这里的`saved_cal`是你应用中存放真实标定结果的`SixStep_Calibration`变量，不是驱动提供的全局变量。不要随意填`zero_deg=0`。当前驱动和示例都不读写Flash；Flash读取、校验和保存由应用负责。仅有一个标记字并不能证明标定数据完整有效。

机械安装、相线顺序、编码器方向配置改变后，旧标定不再当然有效。`SixStep_Init()`会清除RAM标定，因此每次初始化后都需重新标定或重新加载。

## 两台电机

只调用一次`SixStep_Init()`，趁两台都停止时，依次标定或加载id=0、id=1的标定，再开始运行。不要启动电机0后再标定电机1，也不要给第二台再调用一次`SixStep_Init()`。

周期任务中的调用可以是：

```c
result = SixStep_Update(0u, duty0, direction0);
if (result != SIX_STEP_OK) {
    SixStep_StopAll();
    return; /* 从本次周期任务退出 */
}

result = SixStep_Update(1u, duty1, direction1);
if (result != SIX_STEP_OK) {
    SixStep_StopAll();
    return;
}
```

`duty0/1`和`direction0/1`由应用提供，两个编码器共用SPI1，要顺序读取。运行期间不得在另一个中断/任务里抢占该SPI或并发调用这些接口。双路运行要核对每台电机实际获得的更新周期。

## 停止和故障

```c
SixStep_Stop(0u);    /* 关断电机0输出，保留标定 */
SixStep_Stop(1u);    /* 关断电机1输出，保留标定 */
SixStep_StopAll();   /* 关断双路并拉低共用ENABLE，之后必须重新初始化 */
```

关闭驱动是滑行停止，不是主动刹车。单台`Stop()`后，如果周期任务继续传入非零duty，它会再次运行；应同时把应用中该台的duty设为0或停止其非零运行指令。

停止调用`SixStep_Update()`不会自动关断PWM。nFAULT通过软件轮询；当前代码没有精确电流限制、堵转计时或调度超时看门狗。新示例不增加这些功能。

实际输出PWM仍为20kHz（周期50µs）。这个硬件PWM周期与软件读取角度、执行换相更新的周期是两回事。
