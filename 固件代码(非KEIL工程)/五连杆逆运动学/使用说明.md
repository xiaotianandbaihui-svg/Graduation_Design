# 五连杆逆解：足端位置 → AB、ED与+x轴的夹角

把 `leg_ik.c` 和 `leg_ik.h` 加入工程即可。模块只使用C数学库，对外只有 `LegIK_Solve()` 一个函数，固定采用你选定的钻石姿态。几何可达但不符合钻石形的目标也会被拒绝。

## 用法

```c
#include "leg_ik.h"

/* 示例尺寸，实际使用时替换成你的杆长；顺序为L1～L5，单位mm。 */
static const LegIK_Geometry leg = {100, 140, 140, 100, 80};

void Example(void)
{
    LegIK_Angles angle;

    /* 足端位于两舵机轴中点下方160mm。 */
    if (LegIK_Solve(&leg, 0.0f, 160.0f, &angle) == LEG_IK_OK) {
        /* angle.q1_deg：A→B相对+x轴，约133.7162° */
        /* angle.q4_deg：E→D相对+x轴，约 46.2838° */
    }
}
```

输出均为角度制，范围 `[0,360)`；从+x向+y转为正。只有返回 `LEG_IK_OK` 时才使用本次结果。

机器人左右两条腿各调用一次；每条腿都有自己的A、B、P、D、E和局部坐标。原始`+1/-1`是同一条腿两侧的镜像分支，不是机器人左右腿的编号。安装镜像及舵机零位在几何角转舵机指令时处理。

四个舵机一起更新时，先把两条腿都解算成功，再下发四个目标。失败时不发送这次新目标；首次调用失败时，输出可能尚未初始化，不能使用。

```c
LegIK_Angles left, right;
if (LegIK_Solve(&left_geometry, left_x, left_y, &left) == LEG_IK_OK &&
    LegIK_Solve(&right_geometry, right_x, right_y, &right) == LEG_IK_OK) {
    /* 两腿均符合钻石形，再转换安装零位/方向并更新四个舵机。 */
}
```

## 坐标与杆长

```text
                    +x →
            A ●──────O──────● E
             /       │       \
          L1/        │ +y     \L4
           ● B       ↓        D ●
            \                  /
           L2\                /L3
              \              /
                     ● P
```

- 原点O是AE中点，+x向右，+y向下；输入的 `(x_mm,y_mm)` 是足端P相对O的位置。
- L1=AB、L2=BP、L3=PD、L4=ED、L5=AE；A=(-L5/2,0)，E=(L5/2,0)。
- 输出 `q1_deg` 对应A→B，`q4_deg` 对应E→D，二者均相对同一个+x轴。
- 足端P须为两根从动杆的共同铰点。杆件延伸段上的另一点不适用本模型。

## 内部计算

```text
d1 = sqrt((x + L5/2)² + y²)
d4 = sqrt((x - L5/2)² + y²)

q1 = atan2(y, x + L5/2) + acos((L1² + d1² - L2²) / (2 L1 d1))
q4 = atan2(y, x - L5/2) - acos((L4² + d4² - L3²) / (2 L4 d4))
```

先算弧度，再转成度。张开姿态在此坐标系下为左侧取加号、右侧取减号；调用时无需提供分支参数。

固定分支之后，还检查钻石姿态的几何条件（+y向下）：

```text
B.x < A.x，B.y > 0       AB向左下外张
D.x > E.x，D.y > 0       ED向右下外张
P.y > B.y，P.y > D.y     足端低于两肘关节
B.x < P.x < D.x          足端位于两肘关节之间
```

这些条件使理想连杆中心线保持外张、向下收拢且不交叉。比较时保留`1e-5 × 最大杆长`的数值容差，恰好竖直/水平或接近姿态边界也不接受。这里的钻石是图片中的外张形态，不要求四根运动杆等长。

例如尺寸`{100,140,140,100,80}`时，`P=(0,160)`仍输出约`133.7162°/46.2838°`；`P=(100,100)`、`P=(0,-160)`及`P=(0,235)`虽几何可达，但不符合钻石形，会返回姿态错误。

本函数只能保证每个成功返回的**目标位形**。要让实物整个运动过程保持钻石形，初始装配应处于该分支，轨迹中间目标也须逐点检查；不能仅检查两个端点就让舵机大幅跳转。安装零位、舵机跟踪误差及真实杆件厚度仍需实机确认，逆解不能替代机械限位或位置反馈。

## 返回状态

| 返回值 | 含义 |
|---|---|
| `LEG_IK_OK` | 成功，两个角度已写入out |
| `LEG_IK_ARGUMENT_ERROR` | 空指针、非有限数或非法杆长 |
| `LEG_IK_UNREACHABLE` | 目标超出连杆可达范围 |
| `LEG_IK_SINGULAR` | 连杆接近伸直、完全折叠或两从动杆接近共线 |
| `LEG_IK_POSTURE_ERROR` | 目标几何可达，但不符合要求的钻石姿态或太靠近其边界 |

失败时out保持原值。L1～L4须大于0，L5可为0。内部检查几何可达性、奇异位形及钻石姿态，不检查具有厚度的杆件/机身碰撞或舵机限位。共线判断的正弦阈值为0.01，即距0°/180°约0.57°以内拒绝计算；这是数值检查阈值，不是机械安全余量。兼有多种不满足条件时，按参数、可达性/奇异、姿态检查顺序返回最先发现的错误。
