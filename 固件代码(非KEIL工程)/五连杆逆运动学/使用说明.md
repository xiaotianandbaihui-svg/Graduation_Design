# 五连杆逆解：足端位置 → AB、ED与+x轴的夹角

把 `leg_ik.c` 和 `leg_ik.h` 加入工程即可。模块只使用C数学库，对外只有 `LegIK_Solve()` 一个函数，固定采用你选定的张开姿态。

## 用法

```c
#include "leg_ik.h"

/* 示例尺寸，实际使用时替换成你的杆长；顺序为L1～L5，单位mm。 */
static const LegIK_Geometry leg = {100, 140, 140, 100, 80};

void Example(void)
{
    LegIK_Angles angle;

    /* 足端位于两舵机轴中点下方160mm。 */
    if (LegIK_Solve(&leg, 0.0f, 160.0f, &angle) == LEG_IK_OK) {
        /* angle.q1_deg：A→B相对+x轴，约133.7162° */
        /* angle.q4_deg：E→D相对+x轴，约 46.2838° */
    }
}
```

输出均为角度制，范围 `[0,360)`；从+x向+y转为正。只有返回 `LEG_IK_OK` 时才使用本次结果。

## 坐标与杆长

```text
                    +x →
            A ●──────O──────● E
             /       │       \
          L1/        │ +y     \L4
           ● B       ↓        D ●
            \                  /
           L2\                /L3
              \              /
                     ● P
```

- 原点O是AE中点，+x向右，+y向下；输入的 `(x_mm,y_mm)` 是足端P相对O的位置。
- L1=AB、L2=BP、L3=PD、L4=ED、L5=AE；A=(-L5/2,0)，E=(L5/2,0)。
- 输出 `q1_deg` 对应A→B，`q4_deg` 对应E→D，二者均相对同一个+x轴。
- 足端P须为两根从动杆的共同铰点。杆件延伸段上的另一点不适用本模型。

## 内部计算

```text
d1 = sqrt((x + L5/2)² + y²)
d4 = sqrt((x - L5/2)² + y²)

q1 = atan2(y, x + L5/2) + acos((L1² + d1² - L2²) / (2 L1 d1))
q4 = atan2(y, x - L5/2) - acos((L4² + d4² - L3²) / (2 L4 d4))
```

先算弧度，再转成度。张开姿态在此坐标系下为左侧取加号、右侧取减号；调用时无需提供分支参数。

## 返回状态

| 返回值 | 含义 |
|---|---|
| `LEG_IK_OK` | 成功，两个角度已写入out |
| `LEG_IK_ARGUMENT_ERROR` | 空指针、非有限数或非法杆长 |
| `LEG_IK_UNREACHABLE` | 目标超出连杆可达范围 |
| `LEG_IK_SINGULAR` | 连杆接近伸直、完全折叠或两从动杆接近共线 |

失败时out保持原值。L1～L4须大于0，L5可为0。内部检查几何可达性及奇异位形，不检查杆件碰撞或舵机限位。共线判断的正弦阈值为0.01，即距0°/180°约0.57°以内拒绝计算；这是数值检查阈值，不是机械安全余量。
