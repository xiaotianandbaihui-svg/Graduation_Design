# 固定周期串级PID

俯仰角PID外环 → 左右轮速度PID内环。每个实例拥有独立参数、积分和历史误差，各环Kp/Ki/Kd均可设0。

## 创建与调用

```c
BalancePID pid1;
Balance_Init(&pid1);
/* 填写pid1.angle、pid1.speed[0]、pid1.speed[1]的kp、ki、kd */
if (!Balance_Start(&pid1)) {
    /* 配置错误 */
}

/* 固定5ms一次，读取有效角度和轮速后 */
int16_t command[2];
if (!Balance_Update(&pid1, pitch_deg, left_rpm, right_rpm, command)) {
    /* 必须实际发送停止命令 */
}
```

主程序实例见balance_main_example.c，定时器及主循环流程见TIM3调用说明.md。
核心只运算，不读传感器、不配置时钟、不直接停止硬件。

## 参数和方向

- angle.limit：目标机械轮速上限，默认±1000rpm。
- speed[i].limit：电机调制命令上限，默认±1000，必须>0且<=1000。
- upright_deg：目标直立角，默认0度。
- fall_deg：偏离目标超过此值就停止控制，保留你设置的60度。
- 增益默认0是占位；参数修改在停止状态进行，再Start。
- 前倾角为正；左右轮反馈、目标和命令均以各自电角度增加方向为正。

反馈换算：
```c
rpm = encoder_deg_per_s / 6.0f * SVPWM_GetEncoderSign(id);
```
这是机械rpm，不乘极对数。车体前进对应的轮速符号按你在外部的约定处理；左右内环共用一个外环目标，所以两轮对该目标的方向约定须一致。

例：前倾需要负轮速追赶，外环应给出负目标。内环仍用目标减反馈，输出正负直接作为电机dir的正负，不再额外翻转方向。

## 运算

```text
外环误差 = 实际俯仰角 - 目标直立角
内环误差 = 共同目标轮速 - 对应轮的实际轮速

P = Kp × error
I += Ki × error
D = Kd × (error - previous_error)
输出 = 限幅(P + I + D)
```

不传时间参数，按固定周期调参；内外环D都用误差差分，首次/重启后首次D=0。Ki为0时清掉原I项。输出为电压调制命令，不是电流或转矩闭环。

保留积分限幅、条件积分，以及内环饱和时的外环同方向积分暂停。配置只在Start检查，周期中不重复扫描；非法计算结果返回失败并清零两路命令。指针须有效，传感器失败不能复用旧读数。

通用PID可独立使用：
```c
PID p;
PID_Init(&p, 0, 0, 0, 1000);
float u = PID_Update(&p, error);
```
通用PID的有限增益和正limit由调用者保证；异常结果返回NAN，使用前检查isfinite(u)。

## 可选的旧封装

balance_svpwm_example.c也已采用同一方向约定。BalanceSVPWM不再包含安装方向字段：

```c
BalanceSVPWM drive = {0};
Balance_Init(&drive.controller);
/* 填写PID参数；SPI1和CS先完成初始化 */
if (Motor_init()) {
    Balance_SVPWM_Stop(&drive);
    Balance_Start(&drive.controller);
}

/* 固定周期： */
Balance_SVPWM_Control(&drive, pitch_deg, now_ms);
/* 更快地持续调用： */
Balance_SVPWM_MotorUpdate(&drive, now_ms);
```

now_ms仅用于这个可选封装的100ms命令超时，不参与PID整定。主循环精简例程无需这个封装；两套方式不要同时控制同一对电机。

本次只精简方向转换和同步例程，没有改动PID运算、电机标定、SPI或SVPWM底层。
验证包含正/负/零命令、反馈符号、主循环与旧封装、超时和故障停机；没有进行实车稳定性或电流验证。
