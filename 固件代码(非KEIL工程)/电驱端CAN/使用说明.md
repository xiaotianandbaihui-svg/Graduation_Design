# 电驱端 CAN：Pitch、Yaw 两角度通信

STM32F103C8T6标准库，PA11=CAN_RX、PA12=CAN_TX，500kbit/s。对应板1/板5，当前只提供电驱端代码。Roll由主控侧用于腿部调平，不再传给电驱。

## 接入

添加can_pitch.c/.h及标准库stm32f10x_can.c、stm32f10x_gpio.c、stm32f10x_rcc.c、misc.c；已有文件不重复添加。不修改系统时钟。

main.c包含can_pitch.h，删除原来的the_angles和Its_Time_to_PID定义，本模块已定义：

```c
extern volatile float the_angles[2]; /* [0]=Pitch、[1]=Yaw，单位度 */
extern volatile uint8_t Its_Time_to_PID;
```

现有balance_pid.c里的`extern float the_angles[3];`也应删除，改为包含can_pitch.h，以统一数组长度及volatile限定。现有俯仰反馈仍读取the_angles[0]。

这是电驱端的两元素数组。主控MPU9250的角度数组仍是[Pitch, Roll, Yaw]，编码发送时应取主控数组的[0]和[2]，不能取[0]和[1]。

USB_LP_CAN1_RX0_IRQHandler只保留本模块的一份实现；该向量与USB共享，本例不同时使用USB。原定时器不再置PID标志。

完成电机标定和PID初始化后调用一次：

```c
if (!CANPitch_Init()) {
    SVPWM_Stop(0);
    SVPWM_Stop(1);
    while (1) { }
}
```

PCLK1=36MHz时，36MHz / 6 / (1+9+2) = 500kbit/s。CAN直接使用PCLK1，没有定时器的APB倍频规则。

## 报文

| 项目 | 约定 |
|---|---|
| 主控发送、电驱接收 | 标准ID 0x101 |
| 电驱回传、主控接收 | 标准ID 0x102 |
| 帧类型及长度 | 标准数据帧，DLC=4 |
| Data[0]、Data[1] | Pitch，低字节在前 |
| Data[2]、Data[3] | Yaw，低字节在前 |
| 每轴编码 | 16位有符号补码，四舍五入(angle_deg × 100) |
| 解码 | 有符号整数 × 0.01，单位度 |
| 范围、分辨率 | −327.68°～+327.67°；0.01° |

例如Pitch=12.50°、Yaw=−90.00°：

```text
E2 04  D8 DC
Pitch  Yaw
```

主控发送端必须同步改为此格式，旧DLC=6三角度报文会被拒绝。更早的DLC=4单float报文与本版编码不同，不能混用；长度相同不代表能够自动识别。

Yaw若使用0°～360°，发送前将大于180°的值减360°，例如350°发送−10°。解算输出−180°～+180°可直接传输。CAN硬件负责CRC，不另加软件帧头或校验。

## 接收及主循环

CAN接收中断检查ID、帧类型、DLC，再完整更新Pitch和Yaw，最后置Its_Time_to_PID=1。读取编码器和执行PID放在主循环。

同时使用两个角度时，用短临界区取得同一帧快照并清标志：

```c
float angles[2];
uint8_t ready;
uint32_t saved_irq = __get_PRIMASK();
__disable_irq();
ready = Its_Time_to_PID;
if (ready) {
    Its_Time_to_PID = 0;
    angles[0] = the_angles[0]; /* Pitch */
    angles[1] = the_angles[1]; /* Yaw */
}
__set_PRIMASK(saved_irq);

if (ready) {
    /* 用本地angles计算PID；不在临界区内读取编码器或执行PID。 */
}
/* SVPWM_Update仍在PID条件判断外持续调用。 */
```

单个标志位不累计帧数，多帧积压时使用最新数据。PID时间已并入增益，主控应按调参时的固定周期发送；整车程序用已有时基处理通信超时，本模块不实现整车停机策略。

## 回传

```c
CANPitch_Send(angles[0], angles[1]); /* Pitch、Yaw，仅两个参数 */
```

返回1仅表示已提交发送邮箱；0表示邮箱忙、输入非有限或超范围。不等待发送完成，不自动重发旧帧；按需定期发送最新值。

两板均需CAN收发器；CANH接CANH、CANL接CANL，按收发器要求共地，总线两个物理末端各120Ω。PA11/PA12不是CANH/CANL。

验证：标准库头文件语法检查、主机模拟收发测试；未做实板通信测试。
