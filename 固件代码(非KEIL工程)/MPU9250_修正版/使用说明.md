# MPU9250 修正版：五个接口、九轴低通

从原MPU9250_精简版修改。只将本目录的mpu9250_simple.c/.h加入工程，不与旧版同时编译。原目录保留。本版使用软件IIC，不依赖HAL或FreeRTOS。

## 接口与单位

| 接口 | 返回的数据 |
|---|---|
| MPU9250_Init() | 初始化MPU9250及AK8963，重置四元数、积分项、九轴滤波状态 |
| MPU9250_ReadAccel(xyz) | 三轴原始int16计数，16384 LSB/g，±2g |
| MPU9250_ReadGyro(xyz) | 三轴原始int16计数，16.4 LSB/(°/s)，±2000°/s |
| MPU9250_ReadMag(xyz) | AK8963自身坐标系下的原始int16计数 |
| MPU9250_CalcAngles(acc, gyro, mag, dt_ms, angle) | 滤波与解算；输出[Pitch, Roll, Yaw]，单位度 |

五个函数返回1成功、0失败/暂无有效数据。失败时输出数组不变。读数据函数保持原始计数，九轴软件低通在解算入口执行，浮点保存滤波值，不回写为int16造成舍入。原始数据仍可用于标定或独立的冲击检测。

**与旧版不同：**函数名统一为MPU9250_CalcAngles，时间统一为毫秒，例如5.0f代表5ms；输出前两项已交换为Pitch、Roll；Yaw改为−180°～+180°，无需再转换就符合三轴CAN的数值范围。

Pitch范围−90°～+90°，Roll/Yaw范围−180°～+180°。Yaw在边界处会从179°跳到−179°，计算角差时需做环绕处理。Pitch接近±90°时，欧拉角的Roll/Yaw存在奇异性；内部四元数不因此失效。

## 需要提供的底层函数

```c
void SDA(uint8_t level);     // 0拉低，1释放
void SCK(uint8_t level);     // IIC的SCL，0拉低，1释放
uint8_t SDA_Read(void);      // 读取SDA实际电平
void Delay_us(uint32_t us);
void Delay_ms(uint32_t ms);
```

引脚先配置为开漏并配合适上拉，不能推挽强拉高。IIC半周期至少延时3us，实际速度还受GPIO函数耗时影响。AD0为低使用0x68；AD0为高修改.c中的MPU_ADDR为0x69。nCS需为高才能使用IIC。

这个精简总线实现只针对单主机且无时钟拉伸的使用条件，没有SCL回读、多主机仲裁和卡死总线恢复。不要在中断中重入这些函数。Delay函数参数声明必须与工程实际实现一致。

初始化检查MPU9250 ID=0x71、AK8963 ID=0x48；无磁场样本时能启动解算，但不是忽略磁力计芯片初始化失败。加速度/陀螺配置为200Hz，磁力计为16位100Hz连续模式。

## 九轴低通怎么调

在头文件修改：

```c
#define MPU9250_ACCEL_LPF_HZ 30.0f
#define MPU9250_GYRO_LPF_HZ  30.0f
#define MPU9250_MAG_LPF_HZ   10.0f
```

0表示旁路相应软件低通；使用非负有限值。这些是连续RC模型的截止参数，采用后向欧拉离散，数字滤波实际幅频响应也与采样周期有关。

每个轴使用：

```text
tau_ms = 1000 / (2*pi*fc)
alpha  = dt_ms / (tau_ms + dt_ms)
filtered += alpha * (raw - filtered)
```

- 加速度、角速度使用相邻解算输入的实际dt_ms。
- 磁力计只有新数据才更新滤波。解算200Hz、磁场100Hz时，它使用累计的10ms，不能每次都假设为5ms。无新磁场数据时传NULL，不重复传旧数组。
- 首个样本直接作为滤波初值；重新初始化或姿态超时复位后也重新起滤。磁场缺失超过1秒后，下一次有效磁场直接建立新的滤波初值。
- 加速度先按原始模长检查0.8g～1.2g；明显冲击和自由落体不进入重力修正或污染其低通历史。恢复为有效样本时重新建立加速度滤波初值。通过检查的三轴加速度全部滤波。
- 软件低通与芯片内部约41Hz的加速度/陀螺低通串联。降低参数会加强高频衰减，也会增加控制延迟。30Hz RC参数的软件低频延迟约5.3ms，不是整条姿态链路的总延迟。

低通只能衰减毛刺，不能保证异常尖峰完全消失，不能去除持续偏置，也无法区分持续直线加速度与倾斜。不要为了波形更平滑而无限降低滤波参数。

## 精简调用示例

App_GetMs由你已有的毫秒时基提供，不属于本驱动。下面是调用片段，不是完整主控CAN工程：

```c
#include "mpu9250_simple.h"
#include <stddef.h>

extern uint32_t App_GetMs(void);
int16_t accel[3], gyro[3], mag[3];
float angles[3], dt_ms;
uint32_t scheduled_ms = 0, last_ms = 0, now_ms;
uint8_t have_time = 0, mag_ok;

/* 先完成GPIO和时基初始化 */
if (!MPU9250_Init()) {
    while (1) { }   // 初始化失败，不使用角度
}

while (1) {
    now_ms = App_GetMs();
    if ((uint32_t)(now_ms - scheduled_ms) < 5u) continue;
    scheduled_ms = now_ms;

    if (!MPU9250_ReadAccel(accel)) continue;
    if (!MPU9250_ReadGyro(gyro)) continue;
    mag_ok = MPU9250_ReadMag(mag);

    now_ms = App_GetMs();
    dt_ms = have_time ? (float)(uint32_t)(now_ms-last_ms) : 0.0f;
    last_ms = now_ms;   // 送入解算就推进时间，不能只在解算成功时更新
    have_time = 1;

    if (MPU9250_CalcAngles(accel, gyro, mag_ok ? mag : NULL,
                          dt_ms, angles)) {
        // angles[0]=Pitch, angles[1]=Roll, angles[2]=Yaw
        // 此处使用本次角度，后续主控CAN按此顺序编码三个角度。
    }
}
```

加速度和角速度仍是两次独立总线读取，不保证严格同一时刻；实际调度需测量总线和解算耗时。不要将第一次无效输出或失败后保留的旧数组当作本次新角度发送。

已有姿态且间隔超过100ms时，本次返回0、保持输出数组原值，并清除滤波状态。下一帧在加速度接近1g时重新建立姿态；不拿最后一帧角速度推算失去的整段运动。无磁场时重建Yaw从0开始，所以超时后的航向连续性不能保证。即使旧调用者按“距上次成功的时间”重试，也不会因阈值永久卡住，但推荐按示例维护时间。

## 已修复的具体问题

1. 头文件/实现函数名一致，Delay_us有正式声明，移除未使用的旧状态。
2. 毫秒输入只在内部转换一次为秒。
3. 初始化重置全部实际使用的姿态和滤波状态，失败初始化撤销ready。
4. 首次没有有效磁场也能用重力建立Pitch/Roll，Yaw从0开始。
5. 超时后明确使状态失效并允许恢复，不静默夹紧时间继续积分。
6. 输出顺序和航向范围与电驱端三轴CAN协议对应。
7. 磁场用水平朝向atan2角差校正Yaw，解决初始相差180°时仅靠叉积可能不收敛的问题；大于10°的航向误差不进入磁场积分项，减轻初次捕获过冲。
8. 增加九轴软件低通，正确处理磁力计较低的数据更新频率。

## 标定和适用范围

.c顶部gyro_bias填静止时的原始角速度平均值；mag_bias、mag_scale填整机磁场标定结果。默认零偏/比例不代表已完成标定。AK8963出厂系数自动读取，磁轴(My,Mx,-Mz)按芯片手册转到加速度/陀螺坐标，调用方不要重复交换磁轴。

此处的Pitch对应芯片Y轴旋转，不自动识别芯片在车体上的安装方向。若安装有旋转，需要对所有传感器保持一致的坐标变换，并通过实物前倾测试确认俯仰正负。

磁场受电机、电流和铁磁物体影响；Yaw是相对磁北的估计，没有自动补偿磁偏角。持续线加速度引起的假倾角不能只靠这套滤波消除。模拟水平机身持续0.3g的X轴加速度时，最终仍会误判约−16.8°；需要车轮/运动模型等额外信息才能进一步抑制。

加速度当前量程仍是±2g，跳跃或撞击时可能饱和；重力修正会在明显异常时暂停。若修改量程，必须同时修改寄存器和ACCEL_LSB_PER_G，不能只改换算系数。

## 验证

测试在tests/test_mpu9250.c，仅用于电脑模拟，不加入Keil工程。tests/run_tests.ps1使用GCC编译并运行；可通过-Compiler指定gcc路径。硬件接口由可控IIC返回序列替代。

已验证原始读数符号/字节序、IIC应答失败、磁场DRDY和ST2、初始化/超时恢复、75组已知姿态、三轴正反旋转、九轴低通与变采样间隔、200Hz IMU配100Hz磁场、无磁场启动和延后捕获航向。

这是软件逻辑和理想传感器模型测试。未在STM32实板上测量执行耗时，未验证实际振动、电机干扰、磁场标定及平衡稳定性。
